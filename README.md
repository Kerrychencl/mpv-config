## 🌟 核心特色一覽

### 1. ModernZ 深度客製化介面 (OSC)
* **毛玻璃磨砂質感視覺**：播放介面與浮動卡片選單均具備即時背景虛化（Backdrop Blur）與細緻光影。
* **akFace 階層式動態右鍵選單 (Context Menu)**：
  * **全繁體中文現代化階層選單**：
    * 點擊滑鼠右鍵 `MBTN_RIGHT` 或鍵盤 `MENU` 鍵，即可呼叫層級分明的功能選單。
    * 涵蓋 **開啟**、**播放**、**導覽**、**軌道**、**畫質**、**視訊**、**視訊增強**、**音訊**、**字幕**、**彈幕**、**工具**、**視窗**、**結束** 共 12 大分類。
    * **狀態即時反饋**：勾選狀態（核取方塊）、播放狀態、當前音軌/字軌即時高亮顯示。

---

### 2. 播放相關功能
* **自訂動態倍速功能 (`≡+`)**：
  * 倍速選單頂部加入 **`≡+ 自訂倍速`** 按鈕，點擊後即可透過螢幕輸入框輸入任意數值（如 `1.75` 或 `2.2`）。
* **字幕智慧防遮擋（自動抬升）**：
  * 當底部毛玻璃控制列浮現時，程式會同時動態計算並設定 `sub-margin-y` 與 `sub-pos`。
  * 無論是 ASS 特效字幕還是 SRT 純文字字幕，皆能自動向上避讓，杜絕字幕被控制列遮蔽的困擾。
* **縮圖預覽雙引擎**：
  * `thumbfast.lua`：在時間軸/進度條懸停時提供零延遲的畫面即時預覽。
  * `thumbz.lua`：在播放清單、章節列表以及資料夾瀏覽選單中即時生成精緻的視訊截圖縮圖卡片。

---

### 3. 彈幕相關功能
* **彈幕按鈕&彈幕面板**：復古電視外觀，頂部天線，螢幕刻有「彈」字，右下方配備控制旋鈕與齒輪標誌。
* **B站影片掛載**：觀看B站影片時，會自動抓取影片的彈幕。
* **B2Y插件功能**：仿B2Y瀏覽器插件的功能，在看Youtube影片時，可以抓取B站上相同影片的彈幕。
* **Pakku插件功能**：仿Pakku瀏覽器插件的功能，能夠合併相同彈幕並讓放大他的大小。
* **彈幕過濾**：同B站上的彈幕過濾功能，將不想要看到彈幕屏蔽。
* **本地影片彈幕""：打開本地影片時會自動讀取該資料夾內的xml和ass檔案並完成掛載。

---

### 4. SponsorBlock 智慧廣告跳過系統（之Youtube&Bilibili）
* **贊助片段自動跳過**：預設僅全自動跳過商業廣告贊助片（`sponsor`，綠色標記 `#00D482`）。
* **非侵入式互動跳過提示卡片**：
  * 面對片頭（intro）、片尾（outro）、預告（preview）、自我宣傳（selfpromo）等非商業片段，不再強制粗暴跳過。
  * 螢幕下方會浮現精緻的互動式卡片，顯示片段類別與倒數計時，使用者可直接點擊「跳過」，或按下 `Tab` 鍵手動跳過。
  * 若不慎跳過，隨時可按下 `Alt+u` 瞬間復原回到跳過前的秒數。

---

### 5. Bilibili 執行緒撕裂者 (BTR / Threadripper) 串流加速
仿BTR插件的功能，讓海外的觀眾能夠避免因為CDN問題而影片頻繁卡頓的問題
* **多線程並行預讀引擎**：內建獨立後台引擎 (`btr_engine.py`)，針對 Bilibili 等影音串流建立本機快取代理與並行連線，徹底告別 4K / 1080P60 播放卡頓。
* **跨解析度視窗等比自適應縮放**：
  * 面板已支援動態視窗比例縮放算法，會隨 MPV 視窗在 1080p、1440p、4K 螢幕上的解析度自動計算並縮放。
  * 按鈕、字體、滑鼠點擊判定與邊框位置在任何縮放下皆能精確對齊。
* **粉紅色極速銘牌徽章**：
  * 採用專屬粉紅圓角矩形標章（`#FB7299`），左側帶有 3 道速度條紋，右側烙印粗體白色 "B" 字樣。
* **快速呼叫**：按下 `Alt+t` 即可一鍵切換與設定 BTR 加速面板。

### 7. 旗艦級視訊增強與著色器庫 (Shaders)
配置內建完整的現代神經網路與高級影像放大修復著色器，可由右鍵選單快速開啟或組合使用：
* **Anime4K v4.0.1**：
  * **HQ 高畫質模式**：模式 A（平衡修復放大）、模式 B（柔和去模糊/老番）、模式 C（高清去噪細化）、模式 A+A（極致超解析度）、模式 B+B、模式 C+A。
  * **Fast 快速模式**：適用於輕薄筆電或內顯的低負載模式 A/B/C/A+A。
* **FSRCNNX**：基於卷積神經網路的高品質放大濾鏡（收錄 2x16, 2x56, 2x8 以及 SSimSuperRes 與 Krig 色度雙邊濾波組合）。
* **ArtCNN**：專門針對二次元手繪藝術最佳化的深度學習模型（收錄 C4F16, C4F32, v0 C4F8 及抗降採樣 DS 版本）。
* **CuNNy**：二次元神經線條強化器（收錄 faster, fast, 2x12, 4x16, 4x32 系列）。
* **專業獨立濾鏡**：
  * `NNEDI3` (x4 / x6) 神經網路邊緣去交錯與放大
  * `AMD FSR` (EASU / 銳化)
  * `CfL` (色度從亮度預測)
  * `KrigBilateral` (色度雙邊濾波)
  * `SSimSuperRes` / `SSimDownscaler` (結構相似度超解析度與降採樣)
  * `Adaptive Sharpen` (自適應邊緣銳化)
